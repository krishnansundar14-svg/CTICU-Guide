CTICU Quick Reference Guide

General Workflow

Receiving Patients from OR

Before arrival
- Start prelim handoff note (PMH, surgery type)
Handover
Surgeons: - Past history - Surgery details - Drains / tubes - Post‑op plan Anesthesia: - Airway - Lines - Intraop course - Echo (LV/RV function) - Blood products - Rhythm / drips - Paralysis reversed?
First hours
- Monitor bleeding (>200 ml/hr → inform surgeon) - Review labs, CXR, hemodynamics - MAP goal 65–85 - CI >2.2, SvO2 >60 - Warm patient

Plan A Post‑Op Pathway

- Extubate within 6 hrs - Transfer from ICU next day Reasons to delay: - High chest tube output - Low cardiac index - Escalating pressors/inotropes - Poor responsiveness - Failed extubation criteria POD1: - Mobilize - Diuresis - Remove chest tubes / lines - Transfer to floor

Communication Rules

- Over‑communicate Inform surgery team about: - Bleeding >200 ml/hr - Unexpected CT output change - Cardiogenic shock - Inotrope changes Always coordinate: - Vent changes with RT - ECMO changes with ECMO specialist

Surgeries

CABG

Key note: - Document bypassed vessels If unstable: - Tamponade - Graft occlusion → possible cath lab POD1 meds: - Beta blockers - Aspirin - Statin - Lasix

Surgical Aortic Valve Replacement

- Note valve type and size - Daily anticoagulation plan If unstable: - Tamponade - RCA occlusion - LVH volume needs - Pulmonary edema from diastolic dysfunction - Afib intolerance

Mitral Valve Repair

- Document SAM risk - Post‑repair LV function If unstable: - Tamponade - LCx occlusion - SAM / LVOTO - AV block

Common Problems

Cardiogenic Shock

- Inform surgical team - POCUS early (tamponade?) - Check pacer settings Treatment: - Epi / dopamine - Milrinone if MAP allows RV failure: - HR 90‑110 - Maintain sinus rhythm - CVP 12‑15 - Increase inotropes MCS options: - IABP - Impella - RVAD - VA ECMO
